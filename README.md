# Dashboard Grid Practice

A responsive dashboard layout built with CSS Grid.

## Technologies
- HTML5
- CSS3 (Grid, Flexbox, Media Queries)

## Features
- Grid layout with `grid-template-areas`
- Sticky header
- Two-column layout on desktop (main + aside)
- Single-column layout on mobile and tablet
- Full-width header and footer
- RTL support

## Responsive Breakpoints
- Mobile & Tablet: below 1024px → single column
- Desktop: above 1024px → two columns
